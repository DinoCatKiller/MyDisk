# ADR-0002：前端 SolidJS 2 + Tailwind v4 自研组件（弃 HeroUI）

|        |                                        |
| ------ | -------------------------------------- |
| ID     | `D2`                                   |
| 类型   | 决策（**只增不改**）                   |
| 状态   | 已接受                                 |
| 更新   | 2026-10-15                             |
| 何时读 | 想换前端框架 / 引入 React 生态 UI 库时 |
| 规模   | ~0.6k token                            |

## 背景

前端需要一个能高频重渲染上传进度、目录树与虚拟滚动的框架，以及一套可自控的 UI 组件（`A5`）。约束：脚手架已基于 SolidJS 2（`D1`），且原计划的 UI 库为 React-only。

## 备选方案

| 方案      | 说明                                                                                    | 优点                                                         | 缺点                                                                    |
| --------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------- |
| A（选中） | 保留 SolidStart（Solid 2 + Vite + Nitro SSR），UI 用 Tailwind v4 + CSS Modules **自研** | 细粒度响应式天然适合高频进度更新；样式完全可控、无运行时依赖 | 基础组件需自建，前期投入                                                |
| B         | 改用 Next.js + React + HeroUI                                                           | 组件现成、生态大                                             | 与脚手架既有 Solid 代码冲突，需整体重写；React 重渲染模型对进度条不友好 |
| C         | 保留 SolidStart，但仍引 HeroUI                                                          | 省组件工作量                                                 | **HeroUI 为 React-only，无法在 Solid 使用**（技术不可行）               |

## 决定

**采用 A：保留 SolidJS 2 + Vite + Nitro，UI 走 Tailwind v4（`@theme` 定义设计令牌）+ CSS Modules 自研组件；图标用 `lucide-solid`，不可用时回退内联 SVG。**

**最关键的理由：HeroUI 是 React-only，在 Solid 下技术不可行，只能自研 —— 而自研反而让视觉（留白充足的文件管理器观感）完全可控。**

刻意收窄：**不引入**任何 React 生态 UI 组件库；**不在 JSX 里堆超长 class 串**（复杂结构走 CSS Modules）。

## 影响

- 正面：样式与交互完全可控；进度条 / 上传抽屉等高频组件性能好。
- 代价 / 后续动作：基础组件（Button/Input/Modal/Table…）需自建，按 `A5` §2 逐个落地。
- 排期：P1 起（布局与登录页），P2 起密集使用。
